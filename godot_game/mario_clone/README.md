# Mario Clone - Sliding Window Game

A simple Mario-style platformer with a sliding window camera system, implemented in Godot 4.2.1.

## Features
- Automatic scrolling camera
- Basic platforming mechanics (run and jump)
- Simple enemy AI with basic patrolling behavior
- Collision detection and player respawn
- Mario-style level design with platforms and obstacles

## Controls
- A/Left Arrow: Move Left
- D/Right Arrow: Move Right
- Space: Jump

## Development
This game is part of the random_quadrant repository and serves as a demonstration of basic platforming mechanics with a sliding window camera system.

### Project Structure
- `scenes/`: Contains all game scenes and scripts
  - `main.tscn`: Main game scene with level layout
  - `main.gd`: Main scene logic and camera control
  - `player.gd`: Player character controls and physics
  - `enemy.gd`: Enemy AI and interaction logic

## Setup
1. Install Godot 4.2.1
2. Open the project in Godot
3. Run the game from the main scene
